# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, criticize ideas and not people, and accept that the maintainers decide. Any
harassment, insult or personal attack leads to the removal of the comment, then of the author.

Report an unacceptable behavior privately to the maintainer, through the contact of the
[GitHub profile](https://github.com/cygy) of the repository owner. Every report is handled confidentially.
